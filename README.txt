CHINNU'S ADVENTURE — MOBILE VERSION

1. Extract the ZIP.
2. Open index.html on your phone in Chrome.
3. Turn the phone sideways (landscape) for the best experience.
4. Use the on-screen ◀ ▶ buttons to move.
5. Use ⬆ to jump. Your supplied jump sound plays on jumping.

For a real installable Android APK, this web game can later be packaged as an Android app.
